# Furina Art Collection Centre

A simple static website made from `index.html` and `styles.css`, ready for GitHub Pages.

## Add your drawings
1. Put your image files in the `images` folder.
2. Name them `furina-001.jpg`, `furina-002.jpg`, etc. (PNG and WebP also work if you update the matching path in `index.html`).
3. In `index.html`, find the sample artwork cards and change each title, category, artwork ID, and image filename.
4. Copy a card `<article class="art-card"...>` block to add more drawings.

## Publish with GitHub Pages
1. Create a GitHub repository (for example `furina-art-collection`).
2. Upload `index.html`, `styles.css`, and the `images` folder to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then Save.
6. Wait for GitHub Pages to publish and open the URL it provides.

## Important privacy note
GitHub Pages sites are public. A hard-to-guess URL is not a privacy control. Do not upload anything you need to restrict to invited viewers only. This is a fan-made Furina collection and is not affiliated with HoYoverse.
